# 🧟 僵尸围城 (Zombie Siege)

一个使用 HTML5 Canvas 开发的俯视角生存游戏，支持手机、平板和电脑端。

## 🎮 游戏特色

- **俯视角视角**: 从上往下看的游戏视角
- **多平台支持**: 适配手机、平板、电脑
- **虚拟摇杆**: 触摸设备支持虚拟摇杆控制
- **商店系统**: 购买武器、食物、药品、弹药
- **波次系统**: 僵尸一波一波来袭，难度递增
- **本地存档**: 游戏进度自动保存到本地
- **房屋系统**: 可升级的房屋，增加存储空间
- **门防御系统**: 四个方向的门可以锁定、修复、升级

## 🎯 游戏玩法

- 玩家被困在一个房间里，僵尸会从四个门进入
- 使用武器击杀僵尸获得金币
- 在商店购买更好的武器和补给品
- 注意管理生命值和饥饿值
- **锁定门**阻止僵尸进入，但僵尸会攻击门
- **修复和升级门**来增强防御
- **升级房屋**获得更多存储空间
- 尽可能存活更多波次！

## 🏠 房屋系统

### 门系统
- 房屋有四个方向的门（北、南、东、西）
- 门可以**锁定**阻止僵尸进入
- 锁定的门会被僵尸攻击，血量归零后会被破坏
- 门可以**修复**（需要修复工具）
- 门可以**升级**（最高5级），提升血量和防御

### 门等级
| 等级 | 最大血量 | 升级费用 |
|------|----------|----------|
| 1 | 100 | - |
| 2 | 150 | 100💰 |
| 3 | 200 | 200💰 |
| 4 | 300 | 400💰 |
| 5 | 500 | 800💰 |

### 房屋升级
- 房屋可以升级（最高5级）
- 升级房屋增加存储空间
- 存储空间可以存放物品，死亡后不会丢失

| 等级 | 存储格数 | 升级费用 |
|------|----------|----------|
| 1 | 5 | - |
| 2 | 10 | 500💰 |
| 3 | 15 | 1000💰 |
| 4 | 20 | 2000💰 |
| 5 | 30 | 5000💰 |

## 🚀 运行游戏

### 方法一：使用 Node.js 服务器
```bash
# 安装依赖（如果有）
npm install

# 启动服务器
npm start

# 或者
node server.js
```

然后在浏览器中访问 `http://localhost:3000`

### 方法二：直接打开
直接在浏览器中打开 `index.html` 文件（部分功能可能受限）

## 💾 存档系统

游戏会自动保存以下数据到浏览器本地存储：
- 玩家属性（生命、饥饿、金钱）
- 背包物品
- 当前武器
- 游戏进度（波次、击杀数）
- 房屋状态（等级、存储物品）
- 门状态（等级、血量、锁定状态）
- 游戏设置
